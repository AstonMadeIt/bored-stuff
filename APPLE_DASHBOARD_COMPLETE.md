## 📱 Mobile Optimization

- **iPhone Safe Zones**: `padding-inline: max(20px, env(safe-area-inset-left))`
- **Responsive breakpoints**: 768px, 480px
- **Touch-friendly**: All interactive elements sized for thumbs
- **Smooth scrolling**: `-webkit-overflow-scrolling: touch`

## 🎯 Apple Design Principles Applied

1. **Clarity**: Clear hierarchy, readable fonts
2. **Deference**: Content first, UI supports it
3. **Depth**: Layered shadows, blur effects
4. **SF Pro Fonts**: Apple's system fonts throughout
5. **Color System**: 2 variables (--accent, --signal)
6. **Motion**: Smooth, purposeful animations
7. **Accessibility**: High contrast, readable sizes
